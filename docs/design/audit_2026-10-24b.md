**The layering rules and the owner's requirements**

- Rule 1 (the core knows no caller): N25 (the model knows `reads.json`) and N28 (a JavaScript limit in a Parquet writer) break it. The
  engine's errors name the Python keyword `engine='python'` (engine `lib.rs:114`, `palettes.rs:151`, `page_options.rs:101`) and "the
