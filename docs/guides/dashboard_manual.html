Dashboard Manual: Python SDK & JavaScript API

Comprehensive guide to constructing, styling, and programmatically controlling Roadstyle v0.26.2 dashboards.

1 Architecture & Layout Overview

Roadstyle v0.26 replaced legacy single-sidebar layouts with a modern overlay layout:

Element Specification Role
Left Panel 400px fixed width, translucent frame, outer scrollbar Hosts metadata, SQL queries, KPI tiles, and road inspection details.
Right Toolbox Fixed vertical rail with 10 built-in tools Theme, Navigate needle, Street View, Google 3D, Basemap, Roads, 3D Buildings, Legend, Settings, Credits.
Accent Token Sonocount Teal (#0e7c8e light, #42c2d7 dark) Unified contrast token across all controls, focus rings, sliders, and active states.
Synchronous Theme Live twin base map palette Flips light/dark immediately without re-requesting vector tiles.
Phone Form Active at window width ≤ 700px Collapses toolbox to top single-row rail with fold button; panel becomes a 3-height bottom sheet.

2 Python SDK: Building Dashboards

The primary entrypoint is roadstyle.render_dashboard(gdf, ...), which accepts any LineString GeoDataFrame in WGS84 (EPSG:4326).

Basic Python Usage

import geopandas as gpd
import roadstyle as rs

# Load GeoDataFrame of road network
edges = gpd.read_file("stockholm_roads.gpkg")

# Render overlay dashboard with multi-column color options
m = rs.render_dashboard(
    edges,
    name="Stockholm Road Network",
    color_options={
        "Road class": {},
        "Speed limit": {"color_by": "maxspeed_kmh", "cmap": "plasma", "vmin": 20, "vmax": 80},
        "Lanes": {"color_by": "lanes", "cmap": "viridis", "vmin": 1, "vmax": 4},
    },
    basemap="ofm_positron",
    basemaps=["ofm_positron", "ofm_dark", "osm", "esri_gray", "blank"],
)

# Save standalone HTML file
m.save("dashboard.html")

The dashboard={...} Configuration Dictionary

Pass a dictionary to dashboard= to customize the panel, rail, mobile behavior, and window rules:

dashboard = {
    # 1. Left side panel settings
    "panel": {
        "side": "left",          # "left" (default) or "right"
        "width_px": 400,         # Standard width is 400px
        "look": "frame",         # "frame" (translucent border) or "card" (floating card)
        "sections": [            # Custom sections injected into panel
            {
                "id": "stats",
                "label": "Network Metrics",
                "before": "query",  # Position before or after "query" / "selected_road"
                "fold": False,      # True enables accordion chevron collapse
                "html": "<div class='rs-kpis'>...</div>"
            }
        ],
        # Hide default sections if right toolbox already provides them:
        "hide": ["base_map", "colour_by", "legend"]
    },

    # 2. Right rail toolbar settings
    "toolbar": {
        "position": "right",     # "right", "left", "top", or "bottom"
        "navigation": "box",     # "box" (compass needle + sliders) or "buttons" (+, -, 2D/3D)
        "settings": True,        # Enable the Gear settings menu
        "hold": False            # If True, toolbar waits for rs:toolsready before displaying
    },

    # 3. Custom Legend entries
    "legend": {
        "rows": [
            {"color": "#0e7c8e", "label": "Traffic Sensor", "shape": "circle"},
            {"color": "#f59e0b", "label": "Bus Corridor", "shape": "line"},
            {"color": "#ef4444", "label": "Accident Prone", "shape": "square"}
        ]
    },

    # 4. Floating Street View and 3D Windows
    "windows": {
        "clamp": True,           # Keep windows inside the viewport
        "recenter_map": False,   # Do not pan camera when dragging window
        "restore_open": True,    # Restore open windows on reload
        "remember": True         # Remember window sizes and positions
    },

    # 5. Phone layout configuration
    "phone": {
        "max_width_px": 700,     # Breakpoint
        "toolbar": "top"         # Single row scrollable rail at top
    },

    # 6. Data attribution credits
    "credits": [
        {"text": "© OpenStreetMap contributors", "href": "https://www.openstreetmap.org/copyright"},
        {"text": "City Traffic Lab", "href": "https://example.com/traffic"}
    ]
}

rs.render_dashboard(edges, dashboard=dashboard).save("custom_dashboard.html")

3 JavaScript Runtime: Controlling Dashboards

Inside the browser, window.rs provides an interactive object model to query roads, trigger animations, modify the UI, and listen to events.

Tip: In browser console or embedded scripts, access window.rs directly. A script can also wait for readiness via rs.ready(() => { ... }) or document.addEventListener("rs:ready", ...).

1. Road Queries, Selection & Camera Focus

// Query road rows using plain JavaScript predicate
const primaryRoads = rsQuery(p => p.highway === "primary");
const fastRoads = rsQuery(p => p.maxspeed_kmh >= 70 && p.oneway === true);

console.log(`Found ${fastRoads.length} matching roads.`);

// Retrieve properties of road row 42
const props = rs.props(42);
console.log(props.name, props.highway, props.maxspeed_kmh);

// Programmatically select and highlight a road on the map
rs.select(42);

// Smoothly fly camera to center and zoom on a road
rs.focus(42);

// Clear selection
rs.select(null);

2. Dynamic Recoloring & Filtering

// Show only specific road classes, hide tunnels
rs.setFilter({
  classes: ["primary", "secondary", "trunk"],
  bridges: true,
  tunnels: false
});

// Temporarily highlight a set of edges (cyan glow without selecting)
rs.highlight([101, 102, 103]);

// Color-code subsets of edges dynamically (e.g. real-time congestion)
rs.color([
  { ids: [12, 14, 18], color: "#ef4444" }, // Red for congested roads
  { ids: [22, 25, 29], color: "#10b981" }  // Green for free flow
]);

// Clear custom colors (revert to active color option)
rs.color(null);

// Switch active color mode from color_options
rs.setColorBy("Speed limit");

// Switch base map programmatically
rs.setBasemap("esri_gray");

3. Adding & Modifying Left Panel Sections

// Add a new interactive section before the WHERE query box
rs.sections.add({
  id: "live_incidents",
  label: "Live Incidents",
  before: "query",
  fold: true, // Collapsible accordion
  html: `
    <div style="padding: 6px 0;">
      <div style="background: var(--card); border-left: 3px solid #ef4444; padding: 8px; border-radius: 4px; margin-bottom: 6px;">
        <b>Bridge Maintenance</b>: Västerbron speed restricted.
      </div>
      <button class="sb-primary" id="btn-inspect-bridge">Fly to Bridge</button>
    </div>
  `
});

// Attach event listeners inside the custom section
document.getElementById("btn-inspect-bridge").onclick = () => {
  const ids = rsQuery(p => p.name === "Västerbron");
  if (ids.length) {
    rs.select(ids[0]);
    rs.focus(ids[0]);
  }
};

// Fold or unfold programmatically
rs.sections.fold("live_incidents", true);

// Hide or delete section
rs.sections.hide("live_incidents", true);
rs.sections.remove("live_incidents");

4. Extending the Right Toolbox

// Create a custom button element
const btn = document.createElement("button");
btn.type = "button";
btn.title = "Highlight Congestion";
btn.innerHTML = `<svg viewBox="0 0 24 24" width="20" height="20" fill="none" stroke="currentColor" stroke-width="2">
  <path d="M12 2L2 22h20L12 2zM12 9v5M12 18h.01"/>
</svg>`;

btn.onclick = () => {
  const slow = rsQuery(p => p.maxspeed_kmh < 40);
  rs.highlight(slow);
};

// Add to toolbox rail
rs.tools.add("congestion_alert", "button", btn, {
  title: "Congestion Alert"
});

// Disable/enable tools
rs.tools.disable("congestion_alert", "No traffic data available");
rs.tools.enable("congestion_alert");

5. Dashboard Event Bus (rs:*)

Subscribe to user interactions and state changes across the dashboard:

Event Name Triggered When e.detail Payload
rs:select A road is clicked or selected from table { id, properties, overlays, fields }
rs:deselect Selection is cleared {}
rs:themechange Theme toggled (light / dark) { theme: "light" | "dark" }
rs:basemapchange Base map switched { basemap: "osm" | ... }
rs:filterchange Highway class or edge filter updated { classes: [...], bridges: bool, tunnels: bool }
rs:colorchange Color option or edge colors modified { index, option } 
document.addEventListener("rs:select", e => {
  console.log("Road clicked:", e.detail.properties.name);
  console.log("Speed:", e.detail.properties.maxspeed_kmh);
});

document.addEventListener("rs:themechange", e => {
  console.log("Current theme:", e.detail.theme);
});

6. Streaming Live Sensor Data (rs.setData)

Push updates to road features over WebSockets or polling without re-rendering vector tiles:

// Stream real-time traffic speeds
rs.setData({
  1042: { speed_live: 22.4, congestion: "heavy" },
  1043: { speed_live: 54.1, congestion: "clear" }
});
